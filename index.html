What is Fed-Dup?

Fed-Dup is a lightweight, dependency-free tool that duplicates your Git repositories to a secondary platform. Think of it as an insurance policy for your code. If GitHub ever goes down, your repositories are already mirrored on GitLab, Codeberg, or any Git server you choose.

Key Features

  • ✓ Full mirror duplication — all branches, tags, and history
  • ✓ Beautiful Streamlit web UI for management
  • ✓ Automatic background sync on a configurable interval
  • ✓ Optional disk cleanup after each sync
  • ✓ Docker & Docker Compose ready — deploy in one command
  • ✓ Secure — tokens stored locally, never logged
  • ✓ No database — everything in a single JSON file

Quick Start

Clone, configure, and run:

git clone https://github.com/yourusername/fed-dup
cd fed-dup
cp config.json.example config.json   # then edit with your tokens
docker-compose up -d

Then open http://localhost:8501.
