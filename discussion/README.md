# Fed-Dup Discussions

Welcome to the **Fed-Dup Discussions** directory! This directory contains
templates, guides, and reference material for
[GitHub Discussions](https://github.com/feddup/fed-dup/discussions), the
primary channel for community Q&A, ideas, and announcements.

> **Note:** For bug reports and feature requests, use the
> [issue tracker](https://github.com/feddup/fed-dup/issues) with the
> appropriate template. Discussions are for questions, ideas, show-and-tell,
> and general conversation.

## Discussion Categories

GitHub Discussions for Fed-Dup are organized into the following categories:

| Category       | Purpose                                                |
|----------------|--------------------------------------------------------|
| 📣 Announcements | Project news, releases, and important updates (maintainers only). |
| 💡 Ideas        | Feature ideas and proposals for community discussion.  |
| 🙋 Q&A          | Questions about usage, setup, and configuration.       |
| 🙌 Show and tell | Share your Fed-Dup setups, workflows, and integrations. |
| 💬 General      | Anything Fed-Dup-related that doesn't fit above.       |

---

## How to Start a Discussion

1. Go to
   [GitHub Discussions](https://github.com/feddup/fed-dup/discussions).
2. Click **New discussion**.
3. Choose the appropriate **category**.
4. Fill in the title and body. Use a template below if one fits.
5. Add relevant **labels** if available.
6. Post! Community members and maintainers will respond.

---

## Discussion Guidelines

- **Search first.** Your question may already have been answered.
- **Be specific.** Provide context: what you are trying to do, what you have
  tried, and what happened.
- **No tokens or secrets.** Never paste real tokens, passwords, or
  configuration with credentials. Use placeholders like `ghp_YOUR_TOKEN`.
  See [SECURITY.md](../SECURITY.md).
- **Be respectful.** Follow the
  [Code of Conduct](../CODE_OF_CONDUCT.md).
- **Stay on topic.** Keep discussions related to Fed-Dup.
- **Mark answers.** If someone answers your Q&A, mark their reply as the
  answer so others can find it.
- **Don't use discussions for bugs.** Use the
  [issue tracker](https://github.com/feddup/fed-dup/issues) with the bug
  report template for reproducible bugs.

## FAQ

### When should I use Discussions vs. Issues?

- **Discussions:** questions, ideas, general chat, show-and-tell.
- **Issues:** reproducible bugs, concrete feature requests (with the
  templates).

### How long until I get a response?

Fed-Dup is maintained by volunteers. See the response-time table in
[SUPPORT.md](../SUPPORT.md). Q&A discussions are best-effort.

### Can I promote my Fed-Dup integration / tool?

Yes — use the **Show and tell** category. We love seeing how the community
uses Fed-Dup! Just keep it Fed-Dup-related and non-spammy.

### A discussion answered my question — what now?

Mark the helpful reply as the **answer**. This helps others with the same
question find the solution quickly.

### Can I report a security issue in Discussions?

**No.** Security issues must be reported privately. See
[SECURITY.md](../SECURITY.md).
