Fed-Dup

Federated Repository Duplication Engine

A database-free Git mirroring tool that duplicates repositories to a backup host — built with Python & Streamlit. No databases. No lock-in. Just pure git clone --mirror & git push --mirror power.

Capabilities

Everything you need to mirror Git repos

A focused, production-ready toolset — no bloat, no databases, no surprises.

🗄️

Database-Free

No SQL, no SQLite, no Postgres. Configuration lives in a simple JSON file that you can version-control, diff, and edit by hand.

🪞

True Git Mirroring

Uses git clone --mirror and git push --mirror to replicate every branch, tag, note, and ref — byte-for-byte fidelity.

🔐

Secure Token Injection

Authentication tokens are injected via the https://oauth2:{token}@host URL form — never written to disk, never logged.

🎨

Streamlit Web UI

Add, edit, and remove repositories from a clean browser interface. See sync status, results, and disk usage at a glance.

⚙️

Background Worker

Run a persistent daemon or a one-shot --once mode. Perfect for cron jobs, CI pipelines, and Kubernetes CronJobs.

🛡️

Host Allow-List

Restrict destination hosts to a curated allow-list. Block accidental pushes to untrusted or unknown Git servers.

🔏

Token Redaction

Logs, error messages, and exceptions are scrubbed of secrets automatically. Tokens never leak into your observability stack.

📦

Docker-Ready

Ship with a hardened Dockerfile and Docker Compose stack. Persistent volumes, health checks, and non-root execution built in.

🔄

Forward-Compatible Config

Older config files are automatically backfilled with sensible defaults when new fields are introduced. No manual migrations.

🧪

46 Passing Tests

A comprehensive test suite covers config, engine, utils, token handling, and URL sanitization. Quality is baked in, not bolted on.

🧹

Code Quality Gates

Black formatting, flake8 linting, bandit security scanning, and mypy type checks — all enforced in 16 GitHub Actions workflows.

📖

Thoroughly Documented

28 root docs, ADRs, a full wiki, FAQ, deployment guides, and governance — everything an open-source project should ship with.

Quick Start

Get up and running in minutes

Three ways to run Fed-Dup — pick the one that fits your workflow.

install.sh 
# 1 — Clone & enter
git clone https://github.com/yourname/fed-dup.git
cd fed-dup

# 2 — Create a virtual environment & install
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3 — Launch the Streamlit web UI
streamlit run app.py
  → Local URL: http://localhost:8501

# 4 — Run the worker (one-shot mode)
python worker.py --once
  ✓ Mirrored 3 repositories in 4.2s

# 5 — Or run with Docker Compose
docker compose up -d
  → Started fed-dup-web & fed-dup-worker
config.json 
{
  "repos": [
    {
      "name": "my-app",
      "source": "https://github.com/me/my-app.git",
      "destination": "https://backup.example.com/mirrors/my-app.git"
    }
  ],
  "allowed_hosts": ["backup.example.com"],
  "sync_interval": 300
}
